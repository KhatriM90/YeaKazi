# YeaKazi portal

React + TypeScript (Vite). See the repository README for run and test commands.

- `npm run dev` – dev server on :5173, proxies `/api` to the API on :5080
- `npm test` – component tests (vitest)
- `npm run gen:api` – regenerate `src/api/schema.d.ts` from `docs/openapi/yeakazi-api.json`
- Theme tokens: `src/styles/tokens.css` (light/dark, payroll status colours)
