# /rules/ke – Kenyan statutory rule packs

Statutory rates, bands, limits and reliefs live **only** here, as effective-dated
RuleVersion data (Specification Section 13). Application code never hard-codes a rate.

This folder is intentionally empty after S1 Foundation. Rule packs, their loader and
their validation tests are introduced by the payroll slice. No value may be added here
without a cited official source (gazette notice, KRA/NSSF/SHA/AHL publication).
