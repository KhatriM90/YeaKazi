## Slice S1 – Foundation – 2026-10-31
Built: Modular monolith on .NET 10 LTS / EF Core 10 / PostgreSQL 16 (BuildingBlocks, Platform, Organization, Api) plus outbox worker and React + TS (Vite) portal. Tenancy with PostgreSQL row-level security (enabled and forced from the first migration, three least-privilege DB roles, no DELETE grant), tenant bound from the token into the DB session, composite tenant/employer foreign keys. Sign-in with password + TOTP MFA (required for privileged permissions, re-checked per request), lockout, security stamp, rate limiting. Permission catalogue and the 8 Section 6 system roles, custom roles, legal-entity-scoped assignments, separation-of-duties guards. Append-only, SHA-256 hash-chained audit log for every write with search and chain verification. Platform console: platform admins with MFA, idempotent tenant provisioning (SAAS-01) that seeds the first legal entity and invites the tenant administrator via the transactional outbox. Organization setup (ORG-01): legal entities, branches, cost centres, grades, departments, positions with reporting lines (cycle-safe), holiday calendars, work schedules (incl. overnight). Savannah-trust theme with light/dark tokens, tenant logo slot, status badges with text labels, tabular money. Generated OpenAPI + typed client. RFC 7807 errors with correlation ids.
Requirement IDs covered: SAAS-01 (full). ORG-01 (all except payroll groups, deferred to S3, see A-15).

## Slice S2 – Employees – 2026-11-01
Built: People module (schema `people`, RLS forced on all 8 tables, no DELETE grant, composite tenant/employer FKs to org and platform). Employee master with personal details, Kenyan identifiers (KRA PIN, national ID/passport, work permit with 60/30/7-day and expired alerts, NSSF, SHA, HELB, disability certificate), identifiers masked unless `people.sensitive.read` and every unmasked view audited, uniqueness per employer. Effective-dated employment history: episodes (hire → termination, rehire opens a new episode) and assignment versions (job, department, position, branch, cost center, grade, schedule, manager, worker category, pay basis); back/future-dated changes, correct (original kept as cancelled), cancel planned changes, suspend/reinstate, terminate (future-dated, can be withdrawn), rehire; DB trigger blocks rewriting history even for the schema owner; manager loops rejected. Worker category ↔ pay basis rules. Four-eyes payment details (bank/M-Pesa/cash) with a tenant bank-branch reference table. MIG-01 employee import wizard: CSV upload with per-row, per-column errors, all-or-nothing commit by a second user with re-validation, template and column guide. Kenya public holidays as an immutable, effective-dated rule version in /rules/ke loaded by `load-rules`, Sunday rule per Public Holidays Act s.4, per-year statutory load, ad-hoc government announcements with Gazette reference across calendars, new tenants seeded with a KE-PUBLIC calendar.
